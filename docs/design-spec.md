# 意匠の決め方

## 方針

**対応する道路標識があるものは、公式意匠をそのまま使います。** 地図の上で見たときに
「見慣れた標識」であることが何より分かりやすいからです。

| 出所 | 数 | 何を使うか |
|---|---|---|
| 公式意匠 | 43 | 標識令別表第二にもとづく標識SVG（`official/`）を 64×64 に正規化 |
| 自作 | 30 | 対応する道路標識が無いもの（路面標示・信号機など） |

コードごとの出所は [icon-list.md](icon-list.md) の「出所」列にあります。

はじめは全部を自作していましたが、**実物と並べたときに見慣れた形にならなかった**ため、
公式意匠を取り込む方針に変えました。公式のSVGは文字がすでにパス化されているので、
`止まれ`・`50`・`3.3m`・`通行止` といった文字もそのまま入り、
ラスタライズ時にフォントを必要としません。

## 公式意匠の取り込み

`official/` に置いた SVG を `tools/import_official.py` が `icons/<コード>.svg` にします。

- **パスには手を入れません。** ルート要素の `width` / `height` を 64 にし、
  `viewBox` が無ければ元の寸法から補うだけです（元の座標系はそのまま残ります）
- 出典を XML コメントで各ファイルの先頭に入れます
- `<text>` が混ざっていたら止めます（フォントに依存する配信物は作らない）

対応表は [`../data/official_refs.csv`](../data/official_refs.csv)。1つの標識を複数の
コードで共有することがあります（`3` と `81` は 325の3、`112`〜`114` は 323）。

意図して別の標識を当てたものもあります。

| コード | 交通規制種別 | 当てた標識 | 理由 |
|---|---|---|---|
| 7 | 車両通行止め(踏切) | 警戒標識 207のB（踏切あり） | 302 だと `5 車両通行止め` と同じ絵になり、地図で区別できない |
| 12 | 指定方向外進行禁止 | 311-B | 方向は設置ごとに違うので代表を1つ |
| 112〜114 | 最高速度 | 323（50km/h） | 速度は設置ごとに違うので代表を1つ。実際の値は属性で見る |

## 自作するもの

道路標示（路面に描く線や記号）には対応する道路標識がありません。次の30コードは自作です。

```
16 19 20 21 24 52 57 58 60 64 70 76 82 83 86
90 91 92 93 94 98 101 102 107 110 111 116 117 118 119
```

地図で 20〜24px に縮んでも読めるよう、次の体系で描いています。

| 家族 | 台紙 | 例 |
|---|---|---|
| 路面標示 | 灰の路面に白（または黄）の線 | 停止線、中央線の変移、車両通行帯、導流帯、路側帯 |
| 指示 | 青の正方形 | 駐車可、優先本線車道、左折可 |
| 設備 | そのものの形 | 信号機（3灯） |

**自作分では文字を使いません。** ラスタライズする環境にフォントが入っているかどうかで
結果が変わるためです（`tools/verify_icons.py` が `<text>` の混入を検査します）。

色は公式意匠に合わせています。

| 用途 | 値 |
|---|---|
| 赤 | `#ED1C23` |
| 青 | `#0066B3` |
| 白 | `#FFFFFF` |
| 黄（中央線） | `#F2C200` |
| 路面 | `#8A9199` |

## 小さくしたときの読みにくさ

公式意匠をそのまま使うと、次のものは 22px では文字が潰れます。形と色で
「どの家族の規制か」は分かりますが、細かい種別までは読めません。

- `53` 追越し禁止・`69` 駐車余地・`100` 高齢運転者等標章自動車駐車可 — 補助標識の文字が付く
- `112`〜`114` 最高速度 — 数字が読めない（値は属性で見る）
- `4` 通行止め・`8` 歩行者通行止め・`14` 歩行者横断禁止 — 文字が付く

自作分では、次のものが伝わりにくいままです。

- `91` 路面電車停留場 — 電車とホームに見えにくい
- `107` `118` `119` — 通行帯と矢印の組合せ同士の違いが小さい

## 突き合わせ

公式意匠を使っているコードについて、取り込みが崩れていないかを機械的に確かめられます。

```bash
npm run compare              # official/ の意匠と icons/ を並べ、色の構成を比べる
npm run compare -- --strict  # ずれていたら異常終了する
```

自作していた頃は、これで台紙の家族の取り違え（歩行者向けの禁止標識を青の正方形に
していた、原付の右折方法の台紙を間違えていた等）を見つけて直しました。
いまは公式意匠をそのまま使うので、ずれるのは取り込みが壊れたときだけです。

## 変えるとき

1. 公式意匠を増やす → `data/official_refs.csv` に行を足し、`official/` に SVG を置く
2. 自作を直す → `tools/icons_lib.py` の部品か `tools/gen_icons.py` の `DESIGNS`
3. `npm run icons` でアイコンを作り直す（公式意匠の取り込みも走る）
4. `npm run verify` で整合を見る
5. `npm run compare` で公式意匠と突き合わせる
6. `npm run docs` で一覧を作り直し、`npm run build` でスプライトを作る

アイコンを増やすのは、JARTIC の仕様書で新しい規制種別が有効になったときだけです。
`data/codes.csv` は仕様書 表4 の写しなので、そこを直してから `npm run icons` を回すと
定義の無いコードで止まります。
