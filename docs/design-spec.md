# 意匠の決め方

## 何のためのアイコンか

地図の上で「そこにどの交通規制があるか」を一目で分かるようにするためのものです。
道路標識そのものの複製ではありません。

地図では **20〜24px** で描かれます。実物の標識をそのまま縮小すると、
中の文字やピクトグラムは完全に潰れます。そこで次の方針を採っています。

1. **形と色で家族を示す** — 遠目でも「禁止か、指定か、路面標示か」が分かる
2. **中の図形で種別を分ける** — 家族の中での区別は中の図形でつける
3. **文字は使わない**

## 家族

| 家族 | 台紙 | 例 |
|---|---|---|
| 禁止 | 白地・赤の縁（円） | 通行止め、車両通行止め、転回禁止、追越し禁止 |
| 制限 | 白地・赤の縁（円、斜線なし） | 重量制限、高さ制限、最高速度、最低速度 |
| 指定・専用 | 青地（円） | 歩行者用道路、自転車用道路、指定方向外進行禁止、警笛 |
| 駐車・駐停車禁止 | 青地・赤の縁と赤の斜線／× | 駐車禁止、駐停車禁止、駐車余地 |
| 指示 | 青の正方形 | 駐車可、停車可、優先道路、安全地帯、軌道敷内通行可 |
| 横断 | 青の五角形 | 横断歩道、自転車横断帯 |
| 一時停止・徐行 | 逆三角形 | 一時停止（赤地）、徐行（白地・赤縁） |
| 路面標示 | 灰の路面に白（または黄）の線 | 停止線、中央線、車両通行帯、導流帯、路側帯 |
| 一方通行 | 横長の青地 | 一方通行 |

色は Wikimedia Commons の道路標識SVG（標識令別表第二にもとづくもの）で
使われている値に合わせています。

| 用途 | 値 |
|---|---|
| 赤 | `#ED1C23` |
| 青 | `#0066B3` |
| 白 | `#FFFFFF` |
| 黄（中央線） | `#F2C200` |
| 路面 | `#8A9199` |

## 文字を使わない理由

スプライトは SVG をラスタライズして作ります。SVG に `<text>` を置くと、
**ビルドする環境にそのフォントが入っているかどうかで結果が変わります**。
日本語フォントが無い環境では豆腐（□）になり、あっても字形が変わります。
再現できないものは配信物に向かないため、文字は使いません。
`tools/verify_icons.py` が `<text>` の混入を検査します。

そのため、実物が文字だけで種別を表す標識は幾何図形に置き換えています。

| コード | 交通規制種別 | 実物 | このスプライト |
|---|---|---|---|
| 112 | 最高速度(区間) | 赤縁の円に数字（例「50」） | 赤縁の円のみ（数字は属性で見る） |
| 113 | 最高速度可変(区間) | 電光表示 | 赤縁の円に小さな青の四角 |
| 114 | 最高速度(区域) | 数字＋区域の枠 | 赤縁の円を破線の枠で囲む |
| 49 | 最低速度 | 数字に下線 | 赤縁の円に上向きの矢印 |
| 9 | 重量制限 | 「5.5t」 | 上からの荷重の記号 |
| 10 | 高さ制限 | 「3.3m」 | 天井と上下の矢印 |
| 71 | 停車可 | 「停」 | P に下線 |
| 61 | 徐行 | 「徐行 SLOW」 | 白地・赤縁の逆三角形に下向き矢印 |
| 63 | 一時停止 | 「止まれ STOP」 | 赤地の逆三角形 |
| 100〜102 | 高齢運転者等… | 四つ葉の標章 | P に菱形（と時計） |

具体的な速度や重量の値はタイルの属性に入っているので、
ビューワはクリックしたときのポップアップで見せます。

## 見分けにくい組み合わせ

家族が同じで意匠が近いものは、次のように差を付けています。

- **55 二段階右折 / 56 小回り右折** — 二段階は「直進の矢印」と「右向きの矢印」を
  離して置き、小回りは根元から曲がる1本の矢印にする
- **65 駐停車禁止 / 115 駐車禁止** — × と 斜線1本（実物と同じ差）
- **19 立入り禁止部分 / 90 導流帯** — どちらも斜縞。立入り禁止部分には白枠を付ける
- **20 車両通行帯 / 110 普通自転車専用通行帯 / 111 専用通行帯** — 通行帯の線に
  それぞれ 何も無し / 自転車 / 自動車 を置く

## 弱いところ

次のアイコンは、文字を使わない制約のもとでは伝わりにくいままです。
使ってみて分かりにくければ `tools/icons_lib.py` の部品を差し替えてください。

- `9` 重量制限・`10` 高さ制限 — 記号から意味を読み取りにくい
- `91` 路面電車停留場 — 電車とホームに見えにくい
- `106` 環状の交差点における右回り通行 — 環状の矢印が小さい
- `107` `118` `119` — 通行帯と矢印の組合せ同士の違いが小さい

## 変えるとき

1. `tools/icons_lib.py` の部品か `tools/gen_icons.py` の `DESIGNS` を直す
2. `npm run icons` で SVG を作り直す
3. `npm run verify` で整合を見る
4. `npm run docs` で `docs/icon-list.md` を作り直す
5. `npm run build` でスプライトを作る

アイコンを増やすのは、JARTIC の仕様書で新しい規制種別が有効になったときだけです。
`data/codes.csv` は仕様書 表4 の写しなので、そこを直してから
`npm run icons` を回すと未定義のコードで止まります。
