コードは JARTIC 交通規制情報の共通規制種別コード。アイコンのキーはコードそのもので、
MapLibre では `['concat', 'reg:', ['get', 'code']]` で引けます。

（理由は各行の意匠の説明と [design-spec.md](design-spec.md)）。
